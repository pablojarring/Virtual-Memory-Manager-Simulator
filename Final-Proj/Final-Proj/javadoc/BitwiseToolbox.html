      • extractBits

        public static int extractBits(int x,
                              int d1,
                              int d2)
        Given an integer x, extractBits() returns an integer so that: (i) its high 32-(d2-d1+1) bits are zero; and (ii) its low d2-d1+1 bits are the bits between bit d1 (inclusive) and bit d2 (inclusive) in x. Bits in a 32-bit number are numbered 0 to 31, with 0 being the lowest-order bit For instance, if x = 2151, which is 00000000000000000000100001100111 in binary, and if d1=3 and d2=9, then the method "extracts" the bit 3 to bit 9 from x, i.e., bits 0001100, and return the number with these bits as the low bits, i.e., 00000000000000000000000000001100, which is 12 in base 10.
        Parameters:
        x - A 32 bit number
        d1 - A bit index (between 0 and 31)
        d2 - A bit index (between d1+1 and 31)
        Returns:
        An integer

      • getBitString

        public static java.lang.String getBitString(int x,
                                            int d)
        Given an integer x, and a given bit index d (0 ≤ d ≤ 31), this method returns a string that contains the bit string that represents the lowest d+1 bits in x (i.e., all bits up to bit d).

        For instance, if x = 2151, which is 00000000000000000000100001100111 in binary, and d=7, then getBitString() returns "01100111" (which represents decimal 103).

        Parameters:
        x - A 32-bit number
        d - A bit index (between 0 and 31)
        Returns:
        A binary String
