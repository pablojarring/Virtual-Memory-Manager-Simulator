E

extractBits(int, int, int) - Static method in class vmsimulation.BitwiseToolbox
Given an integer x, extractBits() returns an integer so that: (i) its high 32-(d2-d1+1) bits are zero; and (ii) its low d2-d1+1 bits are the bits between bit d1 (inclusive) and bit d2 (inclusive) in x.

G

getBitString(int, int) - Static method in class vmsimulation.BitwiseToolbox
Given an integer x, and a given bit index d (0 ≤ d ≤ 31), this method returns a string that contains the bit string that represents the lowest d+1 bits in x (i.e., all bits up to bit d).
