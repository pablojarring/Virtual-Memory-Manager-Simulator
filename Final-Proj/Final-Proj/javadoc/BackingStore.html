        public BackingStore(int capacity,
                    int pageSize,
                    int seed)
             throws MemoryException
        Creates a backing store with a given capacity (in bytes) and a given page size (in bytes). This constructor is called by Simulator, so no need to call it from your own code for this assignment.
        Parameters:
        capacity - Backing store capacity in bytes (must be a power of 2, strictly greater than 1)
        pageSize - Page size in bytes (must be a power of 2, strictly greater than 1, that divides capacity)
        seed - A random seed to generated initial disk content
        Throws:
        MemoryException - If parameters are invalid
